# 企业券包核销台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript（无新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原有油品价格维护之上补成的企业券包核销闭环：

- **价格维护**：挂牌价调整与状态流转，入场预占取当时的生效价。
- **券包登记**：券写明企业、油品、每升优惠、适用站点、发放批次、有效时段；同企业同油品有效时段重叠的券自动留在待审并写明冲突券码，可人工审核通过或作废；同一券码重复提交只保留首次。
- **入场核销台**：校验券状态、有效时段、适用站点后按当时挂牌价与优惠预占锁价；结算按预占快照生成核销记录（挂牌金额 / 优惠让利 / 门店实收），调价不追溯已入场车辆。
- **核销记录**：结算流水表，含锁定价与各项金额。

## 目录分层

- `src/data/` —— 资料：领域类型（`types.ts`）与种子数据（`seed.ts`）
- `src/domain/` —— 判定：挂牌价取价（`pricing.ts`）、券冲突与入场判定（`coupons.ts`）、预占与结算计算（`settlement.ts`）
- `src/storage/` —— 本机保存：localStorage 读写与键名（`local.ts`）
- `src/components/` + `src/App.vue` —— 页面：价格、券包、入场、核销四个面板与编排

数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限等能力。
