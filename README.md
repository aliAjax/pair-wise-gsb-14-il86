# 企业券包核销台

在原有「油品价格维护」上扩展的企业券包核销台:企业客户持券进站加油,柜台可当场判定券能否使用;入场按当时挂牌价与每升优惠预占,结算生成核销记录,调价不追溯已入场车辆。

## 功能

- **核销台**:输入券码、车牌入场预占(校验券状态、有效时段、适用站点、是否已预占);结算时按入场快照生成核销记录(升数、优惠总额、实收、门店毛利)。
- **券包管理**:券写明企业、油品、每升优惠、适用站点、发放批次、有效时段;同企业同油品有效时段重叠的券留在待审并指出冲突,审核通过前会复查冲突。
- **价格维护**:挂牌价 + 成本价,按生效日期生效,状态流转(生效中 / 待确认 / 已回退)。
- **幂等**:同一券码重复提交只保留首次(登记与入场均拦截)。

## 目录分层

- `src/data/` 资料:类型定义、基础资料(油品 / 站点)、示例数据
- `src/domain/` 判定:价格查询与金额计算、券冲突与可用性、入场与结算规则(纯函数)
- `src/storage/` 本机保存:localStorage 读写与响应式状态
- `src/pages/` 页面:核销台、券包管理、价格维护

## 启动

- 开发:`npm install && npm run dev`
- 构建:`npm run build`

数据保存在浏览器 localStorage(键名前缀 `dfwlfront-9-`),未新增任何依赖。
